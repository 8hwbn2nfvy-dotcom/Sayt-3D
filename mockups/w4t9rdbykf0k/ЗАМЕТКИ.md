# Линк — заметки к макету

Папка: `mockups/w4t9rdbykf0k/`. Статичные HTML-страницы, `style.css`, `script.js` (меню, появление блоков, копирование телефона, шаги заявки). Открывается двойным щелчком по `index.html`, без сервера и без сборки. Данные: `data/link.json` (`static_site: true` — общий шаблон `shablon/build.mjs` этот сайт не пересобирает).

Файлы правил `claude/pravila_makety_tipografii.md`, `claude/pravila_makety_sajtov.md` и `claude/pravila_makety_shinomontazh.md` в репозитории не найдены. Сделано по правилам из задания. Старый макет-одностраничник из загрузок в этой сессии не был приложен; тексты взяты из `data/link.json`.

## Цвета и шрифт

Синий `#178ECF`, жёлтый `#FDEB34`, чёрный — взяты из кода сайта cplink.ru. Шрифт Roboto / Roboto Condensed (на сайте компании); файлы шрифтов не подключаются, без них на устройстве — Arial. Прямые углы, заголовки узкие заглавные. Фоны блоков: синий, белый, жёлтый, голубой, чёрный, подвал тёмно-синий.

## Калькулятора нет

На сайте cplink.ru нет ни одной цены, поэтому калькулятор не сделан (по заданию — только при базовой цене с сайта). В `data/link.json` остались примерные цены прежнего калькулятора (40, 900, 600 ₽) с пометкой `example` — на страницах они не показаны.

## Осталось заменить

- [ ] `[вставить телефон]` — какой номер основной (см. выше).
- [ ] `[вставить цену]` × 6 — цены «от» по направлениям.
- [ ] `[вставить условия доставки]` — сайт пишет «ежедневная бесплатная доставка собственной курьерской службой», условий нет.
- [ ] `[вставить фото: …]` × 6 — фото работ.
- [ ] `[вставить описание входа]` — для схемы.
- [ ] Год основания (на сайте не найден, в макете не упоминается).
- [ ] WhatsApp и Telegram — на сайте их нет, на страницах не показаны.
