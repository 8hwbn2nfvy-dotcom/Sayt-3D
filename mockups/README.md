# Макеты: три типографии (26.11.2026)

Демо для показа владельцам, не боевые сайты. Каждый макет — папка со статичными HTML-страницами, общим для папки `style.css` и `script.js`. Открывается двойным щелчком по `index.html`, без сервера и без сборки. Текст и данные лежат прямо в HTML. Заявки никуда не уходят, внешних карт, шрифтов, сторонних запросов и трекеров нет. На каждой странице — плашка «Макет. Не для публикации» и `noindex, nofollow`.

Страницы: главная, услуги (прайс строками с точками, «от», дата проверки), работы, отзывы, о компании, контакты (нарисованная схема), заявка в 3 шага (файл макета или «нужен дизайн», телефон не короче 10 цифр, «Заявка принята (макет)»). У «Курантов» ещё цены с расчётом по таблицам сайта и страницы визиток, листовок, баннеров. У «Линка» и «Кукурузника» калькулятора нет: на их сайтах нет ни одной цены.

Общее: меню полосой от 1024 px, на телефоне — кнопка «Меню» и панель справа (закрывается крестиком, Esc, ссылкой, затемнением); блоки появляются при прокрутке за 0,5 с со сдвигом 20 px; переходы между страницами — `@view-transition`; `prefers-reduced-motion` всё это отключает.

Все три папки помечены `static_site: true` в данных: старый шаблон `shablon/` (одностраничник с роутером, собирался из JSON) их не пересобирает и для макетов больше не используется.

## Проверка (26.11.2026)

Скриншоты: `proverka/2026-11-26/` — каждая страница трёх сайтов целиком при 390 и 1280 px, меню на телефоне, три шага заявки и «Заявка принята (макет)». Просмотрены выборочно (главные, контакты, услуги).

Проверено автоматически в Chromium (файлы открывались через `file://`):
- ничего не выходит за край экрана при 390 и 1280 px;
- ссылки, кнопки и поля не ниже 48 px;
- на каждой странице плашка «Макет. Не для публикации» и `noindex, nofollow`; на страницах нет слов «уточнить», «для владельца», «по данным сайта»;
- меню: на 1280 — полоса, на 390 — кнопка «Меню»; панель закрывается крестиком, Esc, ссылкой и затемнением;
- заявка: без файла и без «нужен дизайн» шаг 1 не проходит; телефон из 9 цифр не принимается; после «Назад» имя сохраняется; «Отправить» показывает «Заявка принята (макет)»; адрес страницы без параметров; без скрипта форма уходит POST-ом, в адрес ничего не попадает;
- `prefers-reduced-motion`: блоки видны сразу, анимации и плавная прокрутка выключены;
- ни одного запроса в сеть; при переходах по ссылкам и меню консоль без ошибок.

Тонкость: если автотест открывает новую страницу командой, пока идёт переход `@view-transition`, Chromium пишет в консоль «Transition was aborted…». При обычных нажатиях на ссылки (5 переходов на каждом сайте при 390 и 1280 px) этой ошибки нет.
