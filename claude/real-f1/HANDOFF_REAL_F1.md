# HANDOFF: настоящая Aston Martin AMR24 — ролик и страница

Та же сцена и тот же таймлайн, что у Лего-ролика (`claude/lego-f1`), но вместо Лего-машинки — 3D-модель настоящей AMR24. Коробка Лего 77245 в конце осталась.

## Что лежит в папке

```
claude/real-f1/
  CREDITS.md            авторы и лицензии (модель CC BY 4.0, фото CC BY-SA 4.0), текст для титров, товарные знаки
  refs/                 3 фото AMR24 с Wikimedia Commons (1280 px, загрузил владелец)
  model/amr24.glb       исходная модель (23.6 МБ) — НЕ в репозитории (model/.gitignore), см. CREDITS.md
  build/                scene.glb + timeline.json + frames/ (не в репозитории, пересобираются)
  snapshots/            снимки страницы на 0, 4, 7.5, 9.5, 11.5, 13, 15 с и после тапа
  tools/
    car_setup.py        импорт модели в Blender: масштаб (длина 28 единиц = как у Лего), нос в +X, части для разбора, материалы
    real_car.py         замена Лего-машинки в сцене Лего-ролика (для blender_render.py --car-module)
    preview_car.py      пробный кадр одной машины
    export_web_glb.py   облегчённая модель для страницы → web/tools/amr24_web.glb
    glb_webp.py         пересжатие картинок внутри .glb в WebP (Pillow)
  web/
    index.html          страница (модель, загрузчик glTF и коробка встроены), 8.6 МБ
    three.js            тот же ужатый three.js, что у Лего, 1.1 МБ
    video.mp4           15 с, 1920×1080, 30 к/с, 450 кадров, 15.3 МБ (Blender Cycles)
    tools/              index.src.html, build_page.mjs, check.mjs
```

## Как пересобрать

```sh
# 1) сцена и таймлайн со страницы Лего-ролика (камера, трасса, коробка, разобранность/колёса/положение машины по кадрам)
cd claude/lego-f1/web && node tools/build_page.mjs
NODE_PATH=$(npm root -g) node tools/export_gltf.mjs ../../real-f1/build
# 2) видео (≈4.5 ч на 4 ядрах; готовые кадры при повторном запуске пропускаются)
python tools/blender_render.py ../../real-f1/build --car-module ../../real-f1/tools/real_car.py --key-follow --video ../../real-f1/web/video.mp4
# 3) страница
cd ../../real-f1 && python tools/export_web_glb.py && python3 tools/glb_webp.py web/tools/amr24_web.glb 80
cd web && node tools/build_page.mjs && NODE_PATH=$(npm root -g) node tools/check.mjs ../snapshots
```
`python` здесь — Python с модулем `bpy==5.3.0` (Blender как библиотека).

## Модель и части

- Модель «AMR-24 V1» (Abu Saif, Sketchfab, CC BY 4.0). По именам деталей (`TYRE_LF_SUB1_TIRE_TREAD`, `LOD_A_INT`, материалы `force_india_*`) она, вероятно, перенесена из видеоигры F1 — происхождение не проверено.
- В файле материалы упрощены: только цвет, всё матовое, прозрачность текстур не подключена (давало тёмные пятна). `car_setup.fix_materials` подключает прозрачность и задаёт лак (краска/наклейки), полуглянец (карбон), резину (шины), металл, стекло — только для деталей машины.
- 13 частей: 4 колеса (шина, обод, тормоз; крутятся), переднее и заднее крыло, нос, кабина (halo, руль, зеркала, сиденье), два сайдпода, капот, днище, кузов. Наклейки `decal_all_*` отданы части с ближайшей деталью.

## Видео

- Сцена Лего-ролика; Лего-машинка удалена, AMR24 двигается по `timeline.json` (те же значения, что считает страница).
- `--key-follow`: на 12–15 с единственный софтбокс уходит к камере, иначе на езде сзади машина в тени (так было в Лего-ролике).

## Страница

- Облегчённая модель: 270 тыс. → 73 тыс. треугольников (Decimate, детали > 800 треугольников, 20%), текстуры 1024 px в WebP (4.8 → 0.45 МБ). Части и параметры разлёта записаны в модели (extras), страница берёт их оттуда.
- Лимит 3 МБ снят владельцем; страница 9.7 МБ (index.html 8.6 + three.js 1.1).
- Внутри index.html — облегчённая копия модели: публикуя страницу, публикуешь и модель.

## Проверено (2026-11-22, Chromium headless, SwiftShader; Blender 5.3 Cycles CPU)

- Страница с file://, ошибок в консоли нет, 175 деталей машины загружены; тап на 3-й секунде запускает разбор; пробел, стрелка, ползунок работают.
- `video.mp4`: 15.000 с, 1920×1080, 30 к/с, 450 кадров; все 450 PNG целые; кадры на 0, 4, 7.5, 9.5, 11.5, 13, 14.2, 15 с просмотрены.

## Не проверено

- Настоящий телефон и видеокарта; Firefox и Safari; на телефоне 9.7 МБ и 73 тыс. треугольников могут грузиться медленно.
- Звука нет.
- Права: модель (вероятно, из игры) и товарные знаки (Aston Martin, Aramco, F1, LEGO, спонсоры) — для публичной рекламы нужны разрешения.
