# HANDOFF: AMR24 — круг по трассе Барселона-Каталония

Настоящая AMR24 (модель из `claude/real-f1`) стоит на стартовой линии, под портал загораются 5 красных огней — машина разбирается (как в Лего-ролике), перед погасанием собирается, огни гаснут — старт и один полный круг с места на гоночной скорости, табло времени и секторов поверх видео.

## Что лежит в папке

```
claude/barcelona/
  CREDITS.md                 источники и лицензии (контур трассы MIT, рельеф AWS Terrain Tiles, модель CC BY 4.0, шрифт Inter OFL)
  data/es-1991.geojson       осевая линия трассы (bacinger/f1-circuits, MIT) + LICENSE_f1-circuits.md
  data/terrain/*.png         карты высот Terrarium, масштаб 15 (9 тайлов)
  tools/
    track_build.py           трасса в метрах, рельеф, модель скорости, время круга и секторов → build/track.npz
    bcn_scene.py             сцена Blender (дорога, бордюры, гравий, разметка, портал с огнями, земля, солнце+небо), машина, камера, рендер кадров
    overlay.py               табло поверх кадров и сборка web/video.mp4
  web/video.mp4              92.07 с, 1920×1080, 30 к/с, 2762 кадра, 55.8 МБ
  build/                     track.npz, timeline.json, frames/ (не в репозитории)
```

## Как пересобрать

```sh
cd claude/barcelona
python3 tools/track_build.py                   # нужен numpy + Pillow
python tools/bcn_scene.py                      # Python с bpy==5.3.0 и Pillow; ≈19 с на кадр на 4 ядрах CPU, ≈14.5 ч; готовые кадры пропускаются
python3 tools/overlay.py                       # табло + сборка видео (~10 мин)
```
Пробные кадры: `python tools/bcn_scene.py --frames 0,105,900 --samples 12 --scale 50`.

## Таймлайн

| с | что |
|---|---|
| 0–2 | машина на линии, камера сзади-сбоку, впереди портал с огнями |
| 2, 3, 4, 5, 6 | загораются 5 красных огней; с первым машина разбирается (разлёт 1.2 с) |
| 5.4–6.4 | сборка |
| 7.0 | огни гаснут — старт, табло появляется |
| 7.0–89.1 | один круг с места: 1:22.078 (S1 27.099, S2 30.149, S3 24.831) |
| 89.1–92.1 | после финиша, табло с итогом |

## Трасса и скорость

- Осевая линия 4671 м (по данным набора 4655 м), по часовой стрелке; сглажена (σ ≈ 3 м), шаг 1 м. Ширина 12.5 м.
- Рельеф: высоты из тайлов, сглажены вдоль трассы (σ ≈ 40 м); перепад 31.8 м. Земля вокруг подогнана к дороге в полосе ~16 м.
- Скорость: предел в повороте по боковому ускорению с прижимной силой `a = g(grip0 + 0.00042 v²)`, разгон `14(1-(v/95)²)` м/с², торможение `g(1.6 + 0.00055 v²)`; проход вперёд и назад. `grip0` подобран под летящий круг 1:18.0 (гоночный темп 2024: быстрейший круг гонки 1:17.115, средний круг победителя 1:20.3). Круг с места — 1:22.08, максимум 316 км/ч, самый медленный поворот ≈ 109 км/ч.
- Сектора — по официальным длинам 1557 / 1722 / 1376 м, пропорционально длине линии.
- Бордюры (красно-белые, 2 м) и гравий — там, где радиус < 170 м, ±25 м.

## Свет и рендер

- Небо Blender `MULTIPLE_SCATTERING` (без диска солнца, сила 0.22) + лампа «солнце» 2.6, угол 1.2°, высота 48°; AgX Medium High Contrast, экспозиция −0.35.
- Лак машины в этом ролике тоньше (Coat 0.45, Roughness 0.4) — днём полный лак отражал всё небо и краска выглядела хромом.
- Cycles CPU: 14 проходов, адаптивно 0.05, шумодав OpenImageDenoise, размытие движения 0.3.
- Камера: на старте сзади-сбоку с наездом, с 6.8 с плавно уходит в «погоню» (7.2 м позади по трассе, 2 м выше, смотрит на 14 м вперёд).

## Важно для повторного рендера

- Облачную машину усыпляют при простое сессии (около 5 минут без активности) — вместе с ней останавливается рендер. Держать сессию активной (наблюдение за логом, перезапуск каждые 30 мин); рендер продолжает с места остановки.

## Не проверено / упрощено

- Модель скорости простая: времена секторов не совпадут с реальной телеметрией; S1 длиннее реального из-за старта с места; самые крутые повороты (шпилька T10) после сглаживания контура могут быть чуть быстрее реальных.
- Вне трассы — только трава, обочины и рельеф (без трибун, стен, боксов) — по договорённости.
- Камера почти всё время сзади: машина видна в основном с кормы.
- Нет звука.
