## Раздел: 3D-ролик (2026-11-21)

### Что лежит в папке


### Как пересобрать

```sh
cd claude/lego-f1/web
node tools/build_three.mjs /путь/к/three.js/build   # three.js взят из локального репозитория 3Dvetka/three.js
node tools/build_page.mjs
NODE_PATH=$(npm root -g) node tools/check.mjs ../snapshots
NODE_PATH=$(npm root -g) node tools/render_video.mjs   # ≈2.5 мин на программном WebGL
```

### Почему так

- **Обычный скрипт вместо модулей.** Chrome не грузит `<script type="module">` и не даёт WebGL читать картинки с `file://`. Поэтому three.js склеен в один обычный скрипт, а текстура коробки встроена в index.html. Страница открывается двойным кликом без интернета.
- **Одна функция `poseAt(t)`.** Она ставит машинку, части, коробку и камеру для секунды `t`. Страница вызывает её по часам, рендер — по номеру кадра (`t = кадр / 30`), поэтому видео и страница совпадают.
- **Единица длины = 1 шип Лего.** Машинка смотрит носом в +X, длина ≈ 27 шипов, 95 кубиков (длинные кубики режутся на детали ≤ 4 шипов).

### Части и разбор (повторяет логику частей задания)

| Часть | Что в ней | Куда летит |
|---|---|---|
| wheelFL/FR/RL/RR | шина, диск, жёлтая полоска, ступица | вбок и чуть вверх; детали колеса раздвигаются вдоль оси; крутятся |
| frontWing | плоскости, закрылки, торцевые пластины | вперёд |
| rearWing | торцевые пластины, плоскость, зелёно-синяя полоса, балка | назад и вверх |
| cockpit | ванна кабины, пилот, шлем, halo, руль, зеркала | вверх |
| nose | нос, нижняя часть, жёлтые полоски | вперёд-вверх |
| body | днище, сайдподы, капот, «плавник», подвеска | вверх; кубики сильно расходятся |

### Таймлайн

| Секунды | Что происходит |
|---|---|
| 0–7 | машинка стоит, покачивается ±35° (один цикл за 7 с); камеру можно крутить |
| тап или 7.0 | разбор: части разлетаются за 1.2 с, колёса крутятся |
| до 11 | части висят и слегка покачиваются |
| 11–12 | сборка, машинка разворачивается носом по трассе |
| 12–14.8 | ровно один круг по овалу (разгон 0.6 с, торможение 0.8 с), камера сзади-сбоку |
| 11–15 | коробка проявляется и растёт (60 % → 100 %) |
| 14.8–15 | камера переходит на общий план «машинка + коробка»; кадр стоит |

### Управление страницей

Левая кнопка мыши или палец — вращение; колесо или щипок — зум; тап по машинке до начала разбора — разбор сразу; «Сбросить вид» — камера по умолчанию; Пробел — ролик заново; ←/→ — ±0.5 с; ползунок — перемотка. С 12 по 15 с камера едет сама, мышь в это время не действует.

### Проверено (2026-11-21, Chromium headless, программный WebGL SwiftShader)

- index.html открывается с `file://`, ошибок в консоли нет (есть только предупреждения драйвера «GPU stall due to ReadPixels» во время снимков).
- Тап по машинке на 3-й секунде запускает разбор с 3-й секунды; на эмуляции iPhone 13 тап пальцем тоже срабатывает.
- Пробел сбрасывает время и тап; стрелка и ползунок меняют кадр.
- `video.mp4`: h264, 1920×1080, 30/1, 450 кадров, 15.000 с, 7.0 МБ.
- index.html + three.js = 2.77 МБ (лимит 3 МБ).

### Не проверено

- Настоящий телефон (только эмуляция в Chromium) и настоящая видеокарта (только программный WebGL).
- Firefox и Safari.
- Звука нет и не добавлялся.

### Качество текстур поднято до максимума (2026-11-21)

- Текстура коробки заново выровнена из исходного фото в 2048×1024 (было 1024×512), JPEG 92 без субдискретизации цвета (было 82). Больше 2048 смысла нет: на фото коробка занимает около 1500 px в ширину, лишние пиксели деталей не добавят. JPEG 95 не влезает в лимит 3 МБ (≈3.09 МБ).
- Фильтрация: мип-карты + максимальная анизотропия видеокарты (чёткость под углом).
- Тени на странице 4096×4096, как в видео (было 2048).
- Видео: кадры передаются в ffmpeg в PNG без потерь (было JPEG 95), x264 CRF 14 (было 18).

### Машинка по фото: форма и наклейки (2026-11-21)

- **Форма.** Размеры сняты с бокового фото IMG_3999 по сетке «1 шип = 65 px» (`u = 60 + (14 − x)·65`, `v = 1012 − y·65`). Машинка стала выше и ближе к фото: пилот на высоте ≈7 шипов, высокий капот с «плавником», воздухозаборник, наклонный нос (ровная задняя часть + наклонный перед, `sinkFront`), высокое заднее крыло, диффузор, подвеска, зеркала, шлем с визором. Колёса R = 1.85, оси x = 8.6 и −11.05. 106 кубиков.
- **Наклейки.** `tools/make_decals.py` вырезает их из фото и выпрямляет по четырём углам в `tools/decals/*.jpg`; `build_page.mjs` встраивает их в index.html. Боковые — с IMG_3999 (nose_r, nose_f, chassis, cogn, sp_top, sp_low, fin, rw_end, wheel_f, wheel_r), заднее крыло сзади — с IMG_4001 (rw_band, rw_valv, с подчёркиванием резкости, фото размыто), торец переднего крыла — с IMG_4002 (fw_end, снято под углом). Наклейка ложится на внешнюю боковую грань кубика; на другом борту та же картинка, текст читается (раскладка внутри наклейки зеркальна).
- **Свет.** Источник по-прежнему один (направленный), но поднят выше и вперёд; рассеянная заливка 0.85 и отражения 0.9, чтобы теневой борт и наклейки на нём были видны.
- **Размер.** three.js ужат (TypeScript убирает комментарии, затем снимаются отступы): 2087 → 1156 КБ. Коробка теперь JPEG 95. index.html 1184 КБ + three.js 1156 КБ = 2.29 МБ.
- `video.mp4`: 15.000 с, 1920×1080, 30 к/с, 450 кадров, 9.6 МБ.
