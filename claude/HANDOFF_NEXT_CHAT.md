2. окружение: фото-асфальт/трава/гравий, отбойники + сетка, шинные стены, 3 трибуны (35 тыс. мест), 3200 деревьев (Poly Haven, CC0);
3. звук: двигатель V6 по передачам, тормоза, шины, ветер, разбор/сборка, 3 фразы радио (Piper, голос en_US-joe-medium, CC0) — `tools/audio.py`;
4. старт: камера сбоку → облёт назад, пока детали висят; старт с вида сзади;
5. лёгкая облачность (HDRI kloppenheim_07_puresky), без солнца;
6. отражения: лак 0.5, карбон матовее (было «серебро»);
7. качество окружения не хуже машины.

Рендер v2: 2762 кадра, 1920×1080, 30 к/с, 12 проходов, ≈30 с/кадр ≈ 22–23 ч на 4 ядрах CPU.
**Если старый чат рендер не довёл — в новом чате всё восстанавливается с нуля (новая машина не видит старых файлов):**

```sh
# 0) сеть: в среде нужны хосты raw.githubusercontent.com (есть), elevation-tiles-prod.s3.amazonaws.com,
#    api.polyhaven.com, dl.polyhaven.org, huggingface.co, cas-bridge.xethub.hf.co, us.aws.cdn.hf.co
#    (личная среда «3D video (Wikimedia, Sketchfab)» — уже содержит их; запусти новый чат на ней)
# 1) Blender как Python-модуль + пакеты
uv venv bpyenv --python python3.13 && VIRTUAL_ENV=$PWD/bpyenv uv pip install bpy==5.3.0 pillow piper-tts
B=$PWD/bpyenv/bin/python
# 2) модель машины (не в репозитории): Sketchfab «AMR-24 V1» (Abu Saif, CC BY) → claude/real-f1/model/amr24.glb (владелец присылал файл)
# 3) ресурсы и данные
cd claude/barcelona
python3 tools/get_assets.py          # Poly Haven + голос (~500 МБ)
$B tools/build_assets.py             # → assets/lib.blend
$B tools/clean_sky.py                # небо без «звёзд»
python3 tools/track_build.py         # → build/track.npz (нужны numpy, pillow); data/ уже в репозитории
# 4) рендер (долго; готовые кадры пропускаются, можно перезапускать)
setsid nohup $B tools/bcn_scene.py > render.log 2>&1 < /dev/null &
# 5) звук и сборка
$B tools/audio.py                    # → build/audio/mix.wav (нужен build/motion.npz — его пишет bcn_scene.py в начале)

```
Пробные кадры: `$B tools/bcn_scene.py --frames 0,90,205,1100 --samples 12 --scale 50`.

## Важные правила и находки

- Правила владельца: отвечать по-русски на «ты», объяснять просто; неясное — спрашивать; сомнительное помечать 🟡; ничего не скачивать/публиковать без «да»; в конце отчёт (сделано / отличия / не проверено); ничего не удалять из истории.
- **Облачная машина засыпает примерно через 5 минут без активности сессии — рендер умирает.** Во время рендера держать Monitor на лог (перезапуск каждые 30 мин) или проверять прогресс.
- Долгие процессы запускать через `setsid nohup … &` (фоновые задачи сессии живут ≤2 ч).
- Blender 5.3 (`bpy`): `bound_box` кэшируется — после правки вершин нужен `view_layer.update()`; WebP-экспорт glTF не пишет одноканальные картинки; F-кривые через `action.fcurve_ensure_for_datablock`.
- Сосна Poly Haven (17 млн треуг.) не помещается в память — не использовать.
- GitHub не принимает файлы >100 МБ: `assets/`, `build/` в `.gitignore`.
- Права: модель AMR24 вероятно из видеоигры; логотипы спонсоров — товарные знаки; для публичной рекламы нужны разрешения.
